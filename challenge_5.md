# Challenge 5 — Contradictory Data Handling

## Objective

Test the synthesis engine’s ability to:
- rank source reliability
- resolve conflicting claims
- triangulate numerical values
- generate coherent narratives

---

## Source Reliability Hierarchy

| Source Type | Weight |
|---|---|
| SEC Filing | 1.0 |
| Company Report | 0.9 |
| Financial API | 0.85 |
| Major News | 0.8 |
| Web Search | 0.6 |
| Social Media | 0.3 |

---

## Conflict Resolution Example

### Claims

- Web Search: Revenue growth is 9%
- Financial API: Revenue growth is 14%
- SEC Filing: Revenue growth is 13%

### Resolution

The synthesis engine selected the SEC filing claim due to the highest reliability weighting.

---

## Quantitative Triangulation

### Input Values

- 100
- 105
- 98
- 102

### Results

- Average: 101.25
- Minimum: 98
- Maximum: 105
- Spread: 7

## Narrative Synthesis

Microsoft continues to expand cloud operations.

## Conclusion

The synthesis engine successfully:
- prioritized reliable sources
- resolved conflicting information
- triangulated quantitative data
- generated coherent analytical narratives
